# Minggu 20 - Hari 3: Sorting (merge sort) dari nol

## Konsep hari ini (sesi DSA)

- Comparison sort seperti merge sort membagi masalah jadi dua bagian lebih kecil (divide), urutkan masing-masing, lalu gabungkan (conquer) — rekursi murni, pola yang sama seperti minggu 2/7/10/12

## Spesifikasi

- Implementasikan `mergeSort(arr)` secara rekursif (dilarang memakai `.sort()` bawaan)

## Kriteria selesai

```js
console.log(mergeSort([5, 2, 8, 1, 9, 3])); // [1, 2, 3, 5, 8, 9]
```
