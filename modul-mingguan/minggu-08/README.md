# Minggu 08: Asinkron dan event loop (bagian 2)

**Fase:** Fase 1: Runtime JavaScript (minggu 4-10)

**Jalur paralel DSA:** Linked list, stack, queue (minggu 7-9)

## Tujuan

Memahami async/await secara mendalam (urutan eksekusi sekuensial vs paralel), generator dan async iterator dasar, lalu menulis ulang `Promise.all`, `Promise.race`, dan `retry` dengan backoff dari nol. DSA: stack dari nol, dikaitkan ke call stack (minggu 2).
