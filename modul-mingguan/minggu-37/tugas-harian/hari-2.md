# Minggu 37 - Hari 2: Fork & setup lingkungan lokal

## Konsep hari ini — fork & setup

## Tugas

1. Pilih satu proyek dari daftar kandidat hari 1 (boleh dipersempit dulu ke 1-2 favorit)
2. Fork repo-nya, clone ke lokal
3. Ikuti instruksi setup di README (install dependency, dsb)
4. Jalankan test suite lengkap — pastikan semuanya lulus di mesinmu sebelum menyentuh kode apa pun

## Checklist

- [ ] Proyek sudah di-fork dan di-clone
- [ ] Test suite lengkap lulus di lingkungan lokal
- [ ] Kesulitan dicatat di log salah paham
