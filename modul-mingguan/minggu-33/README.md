# Minggu 33: Bundler — AST, resolver, dependency graph

**Fase:** Fase 4: Pola lintas framework (minggu 25-40)

## Tujuan

Memahami AST (representasi tree dari kode), membangun module resolver yang menemukan semua `import` dari sebuah entry file, dan menyusunnya jadi dependency graph — menyambung langsung ke topological sort yang sudah dibangun di minggu 18-19.

## Materi

- [AST Explorer](https://astexplorer.net/) — coba tempel kode JS, lihat AST-nya secara visual
- [Babel parser (@babel/parser) docs](https://babeljs.io/docs/babel-parser)
- [Acorn (parser JS ringan, repo)](https://github.com/acornjs/acorn) — alternatif lebih kecil dari Babel
