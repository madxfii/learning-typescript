# Modul Mingguan

Index modul belajar mingguan, mengikuti [Roadmap TypeScript](../Roadmap%20TypeScript%20Dari%20Tracing%20sampai%20Membedah%20Framework.md) (minggu 1-40, Fase 0-4). Seluruh minggu 1-40 sudah terisi lengkap.

Soal gerbang Fase 0-2 ada di [`assessment.md`](assessment.md) (kunci jawaban di file terpisah [`assessment-kunci-jawaban.md`](assessment-kunci-jawaban.md)). Fase 4 (minggu 25-40) tidak punya jalur DSA paralel — polanya "bangun versi mini lalu bedah source code framework asli", dengan Gerbang Blok tiap 2-3 minggu (bukan satu gerbang di akhir fase seperti Fase 0-3) dan satu Gerbang Akhir di minggu 40 yang menutup seluruh roadmap.
