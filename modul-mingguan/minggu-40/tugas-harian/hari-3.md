# Minggu 40 - Hari 3: Pilih fitur inti untuk dibedah

## Konsep hari ini — pilih fitur inti untuk dibedah

## Tugas

Dari framework yang baru kamu pakai (hari 1-2), pilih **satu fitur inti** yang paling penasaran ingin kamu pahami cara kerjanya di balik layar — idealnya fitur yang kamu pakai langsung di aplikasi kecilmu.

## Cara membedah source code (dari roadmap)

1. Mulai dari satu fitur kecil yang sudah kamu pahami dari sisi pengguna.
2. Clone repo-nya, jalankan test-nya, pasang breakpoint, ikuti alurnya di debugger.
3. Tulis ringkasan satu halaman: bagaimana fitur itu bekerja, dan di mana desainnya berbeda dari versi mini kamu.

Mulai langkah 1-2 dari metode di atas: clone source frameworknya, jalankan test yang relevan dengan fitur pilihanmu.

## Checklist

- [ ] Fitur inti untuk dibedah sudah dipilih
- [ ] Source framework sudah di-clone, test relevan sudah dijalankan
