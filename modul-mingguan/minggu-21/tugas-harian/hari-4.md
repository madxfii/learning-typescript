# Minggu 21 - Hari 4: Mulai proyek full-stack — schema database

## Konsep hari ini (mulai proyek database & full-stack)

- Ini proyek penutup Fase 3: aplikasi nyata yang dipakai orang lain. Hari ini: pilih ide, rancang schema database dasar

## Spesifikasi

- Pilih ide aplikasi nyata yang akan jadi proyek penutup Fase 3 (tool internal untuk tempat kerja/komunitas, atau aplikasi kecil untuk orang di sekitarmu — yang penting **benar-benar dipakai orang lain**, bukan sekadar demo)
- Install PostgreSQL, buat database, rancang schema dasar (minimal 2-3 tabel dengan relasi — misalnya `users`, `posts`, `comments`)
- Tulis query dasar: `SELECT`, `INSERT`, `UPDATE`, `DELETE`, dan satu `JOIN` sederhana untuk memverifikasi relasi antar tabel

## Kriteria selesai

- Schema sudah dibuat (lewat migration file atau SQL langsung), bisa insert data dummy, dan query `JOIN` menghasilkan hasil yang benar
