# Minggu 25: Reactivity — Proxy & dependency tracking dasar

**Fase:** Fase 4: Pola lintas framework (minggu 25-40)

## Tujuan

Memahami `Proxy`/`Reflect` sebagai fondasi reactivity modern (Vue 3, Solid, Preact Signals), dan membangun dependency tracking paling sederhana: siapa yang "membaca" sebuah nilai, dan bagaimana itu didaftarkan otomatis supaya bisa di-notify saat nilai berubah.
