# Minggu 09: Module system (ESM vs CommonJS)

**Fase:** Fase 1: Runtime JavaScript (minggu 4-10)

**Jalur paralel DSA:** Linked list, stack, queue (minggu 7-9)

## Tujuan

Memahami ESM vs CommonJS (live binding vs salinan nilai, circular import), lalu mulai proyek router HTTP mini di atas `node:http` (routing dasar dengan parameter dan query string). DSA: queue dari nol, langsung dipakai sebagai model middleware chain di router minggu depan.
