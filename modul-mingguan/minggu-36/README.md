# Minggu 36: Benchmark & bedah Hono/Fastify

**Fase:** Fase 4: Pola lintas framework (minggu 25-40)

## Tujuan

Mengukur performa radix tree dibanding trie dan loop linear secara nyata, lalu membedah Hono atau Fastify untuk desain router mereka. Ini gerbang penutup blok router, sekaligus menutup seluruh rangkaian upgrade router yang dimulai sejak Fase 1.

## Materi

- [Hono (repo)](https://github.com/honojs/hono) — direkomendasikan (router-nya, termasuk `RegExpRouter`/`TrieRouter`, relatif mudah dibaca)
- [Fastify (repo)](https://github.com/fastify/fastify) — alternatif (memakai `find-my-way`, radix tree router terpisah)
