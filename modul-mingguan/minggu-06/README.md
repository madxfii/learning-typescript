# Minggu 06: Objek, this, dan prototype

**Fase:** Fase 1: Runtime JavaScript (minggu 4-10)

**Jalur paralel DSA:** Big-O, array, hash map, set (minggu 4-6)

## Tujuan

Menguasai 4 aturan penentuan `this` (default, implicit, explicit via call/apply/bind, new), memahami prototype chain dan apa yang sebenarnya dilakukan `class` di baliknya, lalu menulis `EventEmitter` dari nol. DSA: Set, menutup blok DSA minggu 4-6 (Big-O, array, hash map, set).
