# Minggu 30 - Hari 1: Mulai bedah — clone & jalankan test

## Konsep hari ini — mulai dari fitur yang sudah dipahami

## Cara membedah source code (dari roadmap)

1. Mulai dari satu fitur kecil yang sudah kamu pahami dari sisi pengguna.
2. Clone repo-nya, jalankan test-nya, pasang breakpoint, ikuti alurnya di debugger.
3. Tulis ringkasan satu halaman: bagaimana fitur itu bekerja, dan di mana desainnya berbeda dari versi mini kamu.

## Tugas

1. Pilih: Preact (disarankan, ukurannya jauh lebih kecil) atau React.
2. Clone repo-nya, install dependency, jalankan test suite untuk bagian diffing/reconciliation.
3. Cari file yang berisi implementasi diff (di Preact: `diff.js`; di React: reconciler di paket `react-reconciler`).

## Checklist

- [ ] Repo ter-clone, test suite bagian diffing lulus di mesinmu
- [ ] File implementasi diff sudah ditemukan lokasinya
