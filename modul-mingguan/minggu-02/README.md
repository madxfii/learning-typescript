# Minggu 02: Call stack dan closure dasar

**Fase:** Fase 0: Tracing dan model mental eksekusi (minggu 1-3)

## Tujuan

Bisa mengikuti alur pemanggilan fungsi lewat call stack, memahami rekursi sederhana, dan closure dasar (fungsi yang "mengingat" variabel dari luar). Mahir memakai debugger VS Code atau Chrome DevTools: breakpoint, *step over*, *step into*, dan panel variabel/call stack.

## Materi

- [javascript.info: Recursion and stack](https://javascript.info/recursion)
- [javascript.info: Variable scope, closure](https://javascript.info/closure)
- [Python Tutor](https://pythontutor.com) — visualisasi call stack & rekursi langkah demi langkah
- Chrome DevTools Sources panel atau debugger bawaan VS Code — latihan breakpoint, step over, step into
