# Minggu 11: Fondasi yang benar (bagian 1)

**Fase:** Fase 2: Sistem tipe TypeScript (minggu 11-16)

**Jalur paralel DSA:** Rekursi, binary tree, BST (minggu 10-12)

## Tujuan

Menguasai fondasi sistem tipe yang sering disalahpahami: structural typing, cara TypeScript melakukan inferensi otomatis, beda `unknown`/`any`/`never`, literal types, dan `as const`. Mulai membersihkan proyek router Fase 1 dari `any`/`as`/`@ts-ignore`. DSA: lanjut ke binary tree dan BST (dari rekursi minggu 10).
