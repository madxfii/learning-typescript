# Minggu 01: Nilai, referensi, dan scope

**Fase:** Fase 0: Tracing dan model mental eksekusi (minggu 1-3)

## Tujuan

Bisa membedakan nilai primitif (disalin) dari objek (direferensikan), memahami scope global/fungsi/blok, perbedaan `var`/`let`/`const`, dan hoisting. Target akhirnya: bisa memprediksi dengan benar efek `const b = a; b.x = 2;` terhadap `a`, dan menjelaskan kenapa, tanpa menjalankan kode.
