# Minggu 27 - Hari 1: Mulai bedah — clone & jalankan test

## Konsep hari ini — mulai dari fitur yang sudah dipahami

## Cara membedah source code (dari roadmap)

1. Mulai dari satu fitur kecil yang sudah kamu pahami dari sisi pengguna.
2. Clone repo-nya, jalankan test-nya, pasang breakpoint, ikuti alurnya di debugger.
3. Tulis ringkasan satu halaman: bagaimana fitur itu bekerja, dan di mana desainnya berbeda dari versi mini kamu.

## Tugas

1. Pilih satu library: Vue reactivity, Solid, atau Preact Signals.
2. Clone repo-nya, install dependency, jalankan test suite package reactivity-nya — pastikan semua test lulus di mesinmu sebelum mulai membaca kode.
3. Cari implementasi fungsi yang setara dengan `signal()`/`effect()` buatanmu (di Vue: `ref()`/`reactive()` + `effect()`; di Solid: `createSignal()`/`createEffect()`; di Preact Signals: `signal()`/`effect()`).

## Checklist

- [ ] Repo ter-clone, test suite reactivity-nya lulus di mesinmu
- [ ] Fungsi yang setara dengan signal/effect buatanmu sudah ditemukan lokasinya di source
