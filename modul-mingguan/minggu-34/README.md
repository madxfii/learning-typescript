# Minggu 34: Bundler — gabung jadi satu file, bedah Vite/esbuild/Rollup

**Fase:** Fase 4: Pola lintas framework (minggu 25-40)

## Tujuan

Menggabungkan seluruh module dalam dependency graph menjadi satu file bundle yang bisa dijalankan, lalu membedah Vite, esbuild, atau Rollup untuk fitur yang sudah dibangun. Ini gerbang penutup blok bundler.

## Materi

- [Rollup (repo)](https://github.com/rollup/rollup) — direkomendasikan untuk dibedah (ditulis dalam TypeScript/JS, lebih mudah dibaca)
- [esbuild (repo)](https://github.com/evanw/esbuild) — alternatif (ditulis dalam Go, baca dokumentasi arsitekturnya kalau tidak familiar Go)
- [Vite (repo)](https://github.com/vitejs/vite) — alternatif, lebih fokus ke dev-server + memanggil esbuild/Rollup di baliknya
