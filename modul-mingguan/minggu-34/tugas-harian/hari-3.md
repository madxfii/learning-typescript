# Minggu 34 - Hari 3: Mulai bedah — clone & jalankan build contoh

## Konsep hari ini — mulai bedah

## Cara membedah source code (dari roadmap)

1. Mulai dari satu fitur kecil yang sudah kamu pahami dari sisi pengguna.
2. Clone repo-nya, jalankan test-nya, pasang breakpoint, ikuti alurnya di debugger.
3. Tulis ringkasan satu halaman: bagaimana fitur itu bekerja, dan di mana desainnya berbeda dari versi mini kamu.

## Tugas

1. Pilih: Rollup (disarankan, paling mudah dibaca) atau esbuild/Vite.
2. Clone repo-nya, install dependency, jalankan build contoh paling sederhana yang mereka sediakan (biasanya ada di folder `examples`/`test`).
3. Cari implementasi module resolution dan pembuatan dependency graph mereka.

## Checklist

- [ ] Repo ter-clone, build contoh sederhana berhasil dijalankan
- [ ] Implementasi resolver/dependency graph sudah ditemukan lokasinya
