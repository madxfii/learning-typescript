# Minggu 32: Container DI — lifecycle & bedah NestJS/InversifyJS

**Fase:** Fase 4: Pola lintas framework (minggu 25-40)

## Tujuan

Menambahkan lifecycle (singleton vs transient) ke DI container, memahami circular dependency, lalu membedah NestJS atau InversifyJS untuk fitur yang sudah dibangun. Ini gerbang penutup blok DI.

## Materi

- [InversifyJS (repo)](https://github.com/inversify/InversifyJS) — direkomendasikan untuk dibedah (lebih kecil dan fokus, dibanding NestJS yang full framework)
- [NestJS (repo)](https://github.com/nestjs/nest) — alternatif kalau ingin melihat DI dalam konteks framework penuh
